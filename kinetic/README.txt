KINETIC — Free gym / CrossFit studio website template by uiCookies

Concept: A dark, muscular, poster-grade template for strength-and-conditioning gyms
that sell the training, not a wellness spa. The signature element is an interactive
weekly class schedule that switches by day (times, coaches, and level pills), backed
by animated stat counters, a filterable member-results gallery, and honest no-contract
pricing. Deliberately sharp-cornered and high-contrast to feel athletic rather than
soft — a clear counterpoint to the light, friendly personal-trainer siblings in the
same category.

Palette:
  #0d0b0a  obsidian ink      (page base — a warm near-black, not pure grey)
  #1a1714  graphite          (raised surfaces / cards)
  #2c2621  hairline          (borders)
  #ff4a1c  molten orange     (primary accent — CTAs, active states, energy)
  #f7b32b  ember amber        (secondary accent — result stats, intermediate pill)
  #ece5d8  bone white        (primary text — warm off-white)
  #97897b  ash               (muted warm-grey text)

Font pairing:
  Display — Anton (ultra-bold condensed, uppercase poster headlines & big numbers)
  Body/UI — Barlow (a sporty grotesque; 300–700 weights for copy, labels, nav)
  Deliberately NOT Inter / Space Grotesk.

Tech: Bootstrap 5 (self-hosted, relative paths), vanilla JS only (no jQuery), inline-SVG
icons only, Google Fonts via link. Mobile-first 360–1440, skip link, landmarks, ARIA on
tabs/icon buttons, :focus-visible, and prefers-reduced-motion honored throughout.
